# Ben's 3D Prints

A growing collection of small, practical objects I design or adapt for my own use and 3D print. This repository keeps the printable models, previews, and notes together so I can revisit and improve them over time.

Each project has its own directory under `models/`, with an STL file, a preview image, and a README explaining its purpose and dimensions.

## Models

| Model | Purpose |
| --- | --- |
| [TIMEMORE FISH SMART Kettle Stand](models/timemore-fish-smart-kettle-stand/) | A raised stand with a recessed pocket for the kettle's temperature-control base and storage space underneath. |
| [SIM7600 iMessage Gateway](models/sim7600-imessage-gateway/) | Three-piece modem enclosure and interchangeable decorative figurines. |

All model dimensions are in millimeters. Physical fit and printing results depend on the actual hardware and printer; project notes describe the current validation status.
